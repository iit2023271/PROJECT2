# Grade Calculator

Enter marks for 4 subjects and instantly get the total, percentage, and grade.


## Features

- Marks input for 4 subjects
- Total marks out of 400
- Percentage calculated to 2 decimal places
- Grade bands: **A** (80% and above), **B** (60–79%), **C** (40–59%), **D** (below 40%)
- The marking scheme is shown alongside the result

## Tech Stack

- HTML
- CSS
- JavaScript (single self-contained file)

## How to Run

Just open `PROJECT2.html` in any browser. No build step, no server needed.

```bash
# or serve it locally
python3 -m http.server
# then open http://localhost:8000/PROJECT2.html
```

## Example

Marks of 85, 90, 78, 92 give Total 345, Percentage 86.25%, Grade **A** (as shown in the screenshot).
